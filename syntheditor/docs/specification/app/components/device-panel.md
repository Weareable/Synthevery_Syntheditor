# デバイスパネル仕様書

## 概要

デバイスパネルは、接続されているSyntheveryデバイスの状態と装着位置を視覚的に表示するUIコンポーネントです。画面左側にデバイスカードを縦方向に配置し、画面右側に人体アイコンとデバイスの装着位置を表示します。

## レイアウト仕様

### 基本レイアウト
- **画面左領域**: デバイスカードを縦方向に配置
- **画面右領域**: 人体アイコンとデバイス装着位置表示
- **レスポンシブ対応**: 画面サイズに応じてデバイスカードを2列表示に変更可能

### レイアウトパターン
1. **1列レイアウト** (`device_panel_default.png`)
   - デバイスカードを縦方向に1列で配置
   - 人体アイコンとデバイス装着位置を右側に表示

2. **2列レイアウト** (`device_panel_2column.png`)
   - デバイスカードを2列×縦方向で配置
   - 人体アイコンとデバイス装着位置を右側に表示

## デバイスカード仕様

### 表示内容
各デバイスカードには以下の情報を表示します：

1. **デバイスアイコン**: デバイスの色とLED状態を反映
2. **デバイスID**: アルファベット1文字（A, B, C, D, E...）
3. **トラック情報**: 現在選択されているトラック名とアイコン
4. **ナビゲーション矢印**: 左右の矢印（トラックの切り替え）

### デバイスID割り当て
- **接続順序**: `OldestNodeFinder`で決定されるデバイス接続順序に基づく
- **アルファベット順**: 最初に接続されたデバイスがA、次がB、という順序
- **最大数**: 26台まで（A-Z）

### トラック情報表示
- **トラック名**: `CurrentTracksState`から取得したトラック番号を`trackConfig`で検索
- **楽器アイコン**: `TrackCard.tsx`と同様の`InstrumentIcon`コンポーネントを使用
- **表示形式**: "Track1 \n Piano" のような形式

## 人体アイコン表示仕様

### 表示条件
- **装着済みデバイスのみ表示**: `DevicePositionState`で装着位置が設定されているデバイスのみ
- **手持ちデバイスは非表示**: 装着位置が「手持ち」のデバイスは人体アイコンに表示しない

### 装着位置マッピング
- **左腕**: デバイスアイコン + デバイスID（A, B等）
- **右腕**: デバイスアイコン + デバイスID（A, B等）
- **左足**: デバイスアイコン + デバイスID（A, B等）
- **右足**: デバイスアイコン + デバイスID（A, B等）

### 表示スタイル
- **人体アイコン**: 白いアウトラインのシンプルな人体図
- **デバイスアイコン**: デバイスの色を反映した塗りつぶし
- **デバイスID**: 大きなアウトライン文字（A, B, C, D等）

## デバイスアイコンコンポーネント

### 基本仕様
- **コンポーネント名**: `DeviceIcon`
- **表示内容**: デバイスの色とLED状態を視覚的に表現

### 色の取得方法
- **デバイス本体色**: デバイスから取得した色情報（実装予定）
- **LED色**: デバイスのLED状態から取得した色情報（実装予定）
- **フォールバック**: 色情報が取得できない場合はデフォルト色を使用

### アイコンデザイン
- **基本形状**: 正方形のアウトライン
- **内部要素**: 同心円（本体中央のボタンを模したデザイン）
- **色の適用**: デバイス本体色で塗りつぶし、LED色でアクセント表示

## データ取得・状態管理

### 必要な状態
1. **接続デバイス情報**: `mesh.getConnectedDevices()`
2. **デバイス接続順序**: `OldestNodeFinder`（未実装）
3. **トラック選択状態**: `CurrentTracksState`
4. **デバイス装着位置**: `DevicePositionState`
5. **トラック設定**: `trackConfig`（楽器名、アイコン等）

### 実装優先順位
1. **OldestNodeFinder実装**: デバイス接続順序の取得機能
2. **デバイス色取得**: デバイス本体色とLED色の取得機能
3. **DeviceIconコンポーネント**: デバイスアイコンの作成
4. **DevicePanelコンポーネント**: メインコンポーネントの実装

## 技術的実装

### コンポーネント構成
```
DevicePanel
├── DeviceCardList (左側)
│   ├── DeviceCard[]
│   └── DeviceIcon
└── HumanBodyDisplay (右側)
    ├── HumanBodyIcon
    └── DevicePositionMarker[]
```

### 状態管理
- **useDeviceOrder**: デバイス接続順序の管理
- **useDeviceColors**: デバイス色情報の管理
- **useDevicePositions**: デバイス装着位置の管理

### レスポンシブ対応
- **ブレークポイント**: 画面幅に応じて1列/2列レイアウトを切り替え
- **グリッドシステム**: CSS Gridを使用した柔軟なレイアウト
